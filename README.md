# Комплексный анализ клиентской базы интернет-магазина

## Описание проекта

Проведен анализ клиентской базы и транзакций интернет-магазина для выявления точек роста выручки, оптимизации маркетингового бюджета и улучшения удержания клиентов.

**Инструменты:** SQL (SQLite), DBeaver, Power BI  
**Объем данных:** ~540 000 транзакций, 4 340 уникальных клиентов  
**Выручка:** 10,6 млн рублей



## Ключевые бизнес-инсайты

### 1. Операционные потери

Cancellation Rate составляет 8,4% (потерянная выручка ~896 тыс. рублей из 10,6 млн).

**Рекомендация:** Внедрить триггерные уведомления (срок: 1 месяц). Настроить автоматические SMS/email-уведомления на ключевых этапах (сборки, отправления, доставки) для снижения тревожности клиентов и уменьшения числа отмен.

### 2. Здоровье клиентской базы

65,5% клиентов возвращаются (25,7% активных + 39,8% средних) — хороший показатель Retention. Однако 97% клиентов остаются в сегменте трат 1 000–10 000 рублей — это зона роста среднего чека.

**Рекомендация:** Установить порог бесплатной доставки на уровне средний чек + 20% (например, если текущий средний чек 3 000 рублей, порог — 3 600 рублей). Внедрить механики Upsell для перевода клиентов в сегмент "Оптовых".

### 3. Сегментация "Одноразовых" клиентов (34,4%)

Выявлена неоднородность сегмента:
- "Одноразовые + Лояльные" (чек 1 000–10 000 рублей) — цель для реактивации через триггерные рассылки
- "Одноразовые + Оптовые" (чек >10 000 рублей) — вероятные B2B-клиенты, исключить из массовых рассылок

**Рекомендация:** Разделить 1 494 клиента на три подгруппы:
- Группа 1 (чек <1 000 рублей, ~60% сегмента): Мелкие покупки, низкий потенциал. Не тратить бюджет на реактивацию.
- Группа 2 (чек 1 000–10 000 рублей, ~35% сегмента): "Одноразовые + Лояльные". Главная цель для реактивации.
- Группа 3 (чек >10 000 рублей, ~5% сегмента): "Одноразовые + Оптовые". Вероятные B2B или покупатели дорогих товаров.

### 4. География продаж

UK — лидер по общей выручке (домашний рынок). EIRE (Ирландия) — лидер по выручке на клиента (высокомаржинальный рынок).

**Рекомендация:** Увеличить маркетинговый бюджет в Ирландии, протестировать повышение цен в UK.

### 5. Топ-товары (после очистки от сервисных строк)

REGENCY CAKESTAND 3 TIER — лидер по выручке (174 484 рублей) — приоритетное складское хранение. PAPER CRAFT, LITTLE BIRDIE — лидер по объему (80 995 штук) — использовать как товар-приманку в акциях.

**Рекомендация:** Создать товарные наборы (bundles) для увеличения среднего чека на 15-20%.



## SQL-запросы

Все запросы, использованные в анализе, находятся в файле [sql-запросы.sql](sql-запросы.sql).

Запросы включают:
- Расчет выручки с отмененных заказов и общей выручки
- RFM-сегментация клиентов по частоте и сумме покупок
- Анализ выручки по странам с расчетом выручки на клиента
- Топ-10 товаров по выручке с очисткой от сервисных строк
